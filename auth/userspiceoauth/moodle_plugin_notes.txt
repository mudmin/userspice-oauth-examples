Moodle UserSpice OAuth Authentication Plugin Notes
-------------------------------------------------

This directory (`userspiceoauth`) contains the files for a Moodle Authentication plugin. It allows users to log in to Moodle using their UserSpice account credentials via the OAuth2 protocol.

**Plugin Files:**

*   `auth.php`: The main plugin class (`auth_plugin_userspiceoauth`) extending `auth_plugin_base`. It handles the core OAuth logic, user creation, and updates.
*   `settings.php`: Defines the administration settings page for the plugin, allowing configuration of UserSpice server details, client credentials, and field mappings.
*   `version.php`: Contains plugin version information, Moodle compatibility requirements, and dependencies.
*   `lang/en/auth_userspiceoauth.php`: English language strings for the plugin's interface, settings, and messages.
*   `login.php`: An entry point script that initiates the OAuth flow by redirecting the user to UserSpice. This is typically linked from a "Login with UserSpice" button.
*   `callback.php`: The script that UserSpice redirects back to after authorization. It handles exchanging the code for a token, fetching user info, and completing the Moodle login.
*   `index.php`: A placeholder file, usually redirecting to the Moodle login page.
*   `lang/en/index.html`, `lang/index.html`: Prevent directory listing.

**Installation:**

1.  **Place the Plugin:**
    *   Copy the entire `userspiceoauth` directory into your Moodle installation's `auth/` directory.
    *   The path should look like: `<moodle_root>/auth/userspiceoauth/`.

2.  **Install through Moodle Admin:**
    *   Log in to your Moodle site as an administrator.
    *   Navigate to "Site administration" > "Notifications" (Moodle will usually detect the new plugin here).
    *   Follow the on-screen prompts to install/upgrade the plugin. Moodle will run any installation scripts (though this plugin doesn't have custom DB tables initially).

**Configuration:**

1.  **Enable the Plugin:**
    *   Go to "Site administration" > "Plugins" > "Authentication" > "Manage authentication".
    *   Find "UserSpice OAuth" in the list and enable it by clicking the eye icon (it should not be greyed out).
    *   You might want to move it up in the list if you want it to be a prominent option.

2.  **Configure Settings:**
    *   On the same "Manage authentication" page, click the "Settings" link for "UserSpice OAuth".
    *   Alternatively, find the settings page directly under "Site administration" > "Plugins" > "Authentication" > "UserSpice OAuth".
    *   You **must** configure the following:
        *   **UserSpice Server URL:** Base URL of your UserSpice installation (e.g., `https://example.com/usersc/`).
        *   **Client ID:** Your UserSpice OAuth client ID.
        *   **Client Secret:** Your UserSpice OAuth client secret.
        *   **Endpoint Paths:** (Authorization, Token, User Info) - defaults are provided but verify they match your UserSpice setup.
        *   **Scope:** Scopes to request (e.g., `profile email`).
        *   **Auto-create Moodle User:** Enable to create Moodle accounts for new UserSpice users.
        *   **Update user info on login:** Enable to sync profile data from UserSpice on each login.
        *   **User Field Mapping:** Specify which UserSpice user info fields map to Moodle's firstname, lastname, email, and optionally username.

3.  **Set Redirect URI in UserSpice:**
    *   In your UserSpice OAuth Server plugin configuration (for the client application you created for Moodle), you **must** set the **Redirect URI**.
    *   The settings page for this Moodle plugin will display the correct Callback URL to use. It will be:
        `https://your-moodle-site.com/auth/userspiceoauth/callback.php`
        Replace `https://your-moodle-site.com` with your actual Moodle site's base URL.

**Usage - Login Button:**

Moodle can automatically display a login button for enabled authentication plugins that support it (like this one, via `loginpage_idp_branding` and `loginpage_idp_link` methods in `auth.php`).

1.  **Automatic Button (Recommended):**
    *   Ensure the plugin is enabled.
    *   Often, Moodle's login page will automatically list enabled identity providers if the theme supports it or if "Show Identity Providers on Login Page" (or similar setting in Site Admin > Appearance > Themes) is enabled.
    *   The button text is "Login with UserSpice" (customizable via language string if needed).

2.  **Manual Link (if needed):**
    *   If the button doesn't appear automatically, or you want to place it elsewhere, the link to initiate the login is:
        `https://your-moodle-site.com/auth/userspiceoauth/login.php`

**Important Notes:**

*   **HTTPS:** Both your Moodle site and UserSpice server **must** run on HTTPS for security.
*   **UserSpice API Fields:** The plugin expects certain field names from the UserSpice user info endpoint (e.g., `email`, `fname`, `lname`, `username`). These are configurable in the plugin settings under "User Field Mapping".
*   **Moodle Cron:** Ensure Moodle's cron job is running regularly, as it handles various background tasks.
*   **Testing:**
    *   Test with a new UserSpice user to see if account creation works.
    *   Test with an existing Moodle user (whose email matches a UserSpice user) to see if login works.
    *   Test user profile updates if enabled.
*   **Debugging:** Enable Moodle's debugging features (Site administration > Development > Debugging) if you encounter issues. Errors from this plugin are often logged using `mtrace()`.
*   **Moodle Version Compatibility:** This plugin is set for Moodle 3.10+ (requires `2020110900`). Adjust `version.php` if targeting other specific Moodle versions.
