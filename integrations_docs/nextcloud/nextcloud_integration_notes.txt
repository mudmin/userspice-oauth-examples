Nextcloud UserSpice OAuth Integration Notes
-------------------------------------------

This document outlines how to integrate UserSpice OAuth with Nextcloud, allowing users to log in to Nextcloud using their UserSpice credentials.

Nextcloud has built-in support for generic OAuth 2.0 identity providers. This is the preferred method as it doesn't require installing a custom Nextcloud app, only configuration on both UserSpice and Nextcloud.

**Assumptions:**

*   You have a working UserSpice installation with the OAuth Server plugin enabled and functional.
*   You have administrative access to your Nextcloud installation.
*   Your UserSpice OAuth server provides a standard user information endpoint that returns user details (like ID, username, email, display name) in JSON format when queried with a valid access token.

**Steps for Integration:**

**Part 1: UserSpice OAuth Server Configuration**

1.  **Create an OAuth Client in UserSpice:**
    *   In your UserSpice installation, go to the OAuth Server plugin settings.
    *   Create a new OAuth client application specifically for Nextcloud.
    *   **Client Name:** Something descriptive, e.g., "Nextcloud Login".
    *   **Redirect URI / Callback URL:** This is crucial. You will get this URL from Nextcloud in Part 2, Step 3. It will look something like:
        `https://your-nextcloud-domain.com/ocs/v2.php/apps/user_oidc/api/v1/oidc-callback` (if using OpenID Connect user backend)
        OR
        `https://your-nextcloud-domain.com/apps/sociallogin/oauth/custom` (if using Social Login with a custom OAuth2 provider - less likely for this approach)
        OR
        Nextcloud might provide a specific callback URL when you configure a generic OAuth2 provider. **You will need to find this URL in the Nextcloud admin settings when adding the provider.** A common pattern for generic OAuth2 might be `https://your-nextcloud-domain.com/index.php/apps/user_oauth2/callback/` or similar.
        **For now, leave this as a placeholder or use your Nextcloud base URL; you will update it later.**
    *   Note down the **Client ID** and **Client Secret** provided by UserSpice. You will need these for the Nextcloud configuration.

**Part 2: Nextcloud Configuration (as Administrator)**

Nextcloud offers a few ways to integrate OAuth2. The most straightforward is usually via a built-in option or a commonly available app.

**Method A: Using Nextcloud's built-in OpenID Connect / OAuth 2.0 user backend (if available and UserSpice is compatible)**

Some Nextcloud versions or distributions might have a more direct way to add OIDC/OAuth2 providers for user authentication. The app `user_oidc` is often used for this.

1.  **Install `user_oidc` app (if not already installed):**
    *   Go to "Apps" in Nextcloud.
    *   Find and enable the "OpenID Connect user backend" (`user_oidc`) app or a similar generic OAuth2 user backend app.

2.  **Configure the OpenID Connect / OAuth 2.0 Provider:**
    *   Navigate to "Administration settings" > "Security" > "OpenID Connect" (or similar section for OAuth2).
    *   Click "Add provider" or "Configure".
    *   You will need to fill in the following details:
        *   **Identifier / Internal Name:** A unique name, e.g., `userspice`.
        *   **Client ID:** The Client ID from UserSpice (Part 1, Step 1).
        *   **Client Secret:** The Client Secret from UserSpice (Part 1, Step 1).
        *   **Discovery endpoint URL OR Manual Configuration:**
            *   **Discovery (Preferred if UserSpice supports it):** If UserSpice OAuth Server exposes an OpenID Connect Discovery document (usually at `/.well-known/openid-configuration` relative to the server URL), you can enter that URL here. Example: `https://your-userspice-server.com/usersc/plugins/oauth_server/.well-known/openid-configuration` (This path is hypothetical for UserSpice).
            *   **Manual Configuration (More likely for generic UserSpice OAuth):**
                *   **Authorization Endpoint:** `https_://your-userspice-server.com/usersc/plugins/oauth_server/auth.php` (Replace with your actual UserSpice auth endpoint).
                *   **Token Endpoint:** `https_://your-userspice-server.com/usersc/plugins/oauth_server/auth.php` (Replace, often same as auth for UserSpice).
                *   **User Info Endpoint (Profile URL):** `https_://your-userspice-server.com/usersc/plugins/oauth_server/api.php` (Replace, this endpoint must return user details as JSON).
        *   **Scope:** `profile email` (or whatever scopes UserSpice provides and Nextcloud needs, e.g., `openid profile email` if trying to mimic OIDC).
        *   **Logout URL (Optional):** If UserSpice has a central logout URL.
        *   **Field Mappings (Crucial):**
            *   **UID Claim / Attribute for unique user ID:** The field from UserSpice's user info response that uniquely identifies the user (e.g., `id`, `sub`, `username`).
            *   **Display Name Claim:** Field for user's full name (e.g., `name`, `fname` + `lname` if you can combine, or just `username`).
            *   **Email Claim:** Field for user's email (e.g., `email`).
            *   Other mappings as needed (groups, etc., if supported).
        *   **Button Text:** "Login with UserSpice".

3.  **Get the Callback URL from Nextcloud:**
    *   During or after configuring the provider in Nextcloud, Nextcloud will display the **Redirect URI / Callback URL** that it expects.
    *   **Copy this URL exactly.**

4.  **Update UserSpice Client Configuration:**
    *   Go back to your UserSpice OAuth Server settings (Part 1, Step 1).
    *   Update the **Redirect URI** for the Nextcloud client with the URL you copied from Nextcloud.

**Method B: Using the "Social Login" App (if Method A is not suitable or UserSpice needs a more custom mapping)**

The "Social Login" app allows adding custom OAuth2 providers.

1.  **Install "Social Login" app:**
    *   Go to "Apps" in Nextcloud, find and enable "Social Login".

2.  **Configure Custom OAuth2 Provider:**
    *   Go to "Administration settings" > "Social login".
    *   Scroll down to "Custom OAuth2/OIDC providers".
    *   Click "Add new provider".
    *   **Internal name:** `userspice`
    *   **Title:** `UserSpice`
    *   **Authorize url:** `https_://your-userspice-server.com/usersc/plugins/oauth_server/auth.php`
    *   **Token url:** `https_://your-userspice-server.com/usersc/plugins/oauth_server/auth.php`
    *   **Profile url (User Info URL):** `https_://your-userspice-server.com/usersc/plugins/oauth_server/api.php`
    *   **Client Id:** The Client ID from UserSpice.
    *   **Client Secret:** The Client Secret from UserSpice.
    *   **Scope:** `profile email`
    *   **Profile Fields (JSON Path or attribute name):**
        *   **Unique User ID:** `id` (or `username`, if it's unique and stable)
        *   **Displayname:** `username` (or `fname` and `lname` if the app allows combining)
        *   **Email (optional but recommended):** `email`
    *   **Button style, icon etc.:** Configure as desired.

3.  **Get Callback URL and Update UserSpice:**
    *   The Social Login app will also have a specific callback URL, often in the pattern of `https://your-nextcloud-domain.com/apps/sociallogin/oauth/custom` or similar, potentially including the internal name. Find this and update your UserSpice client's Redirect URI.

**General Nextcloud Settings for External Logins:**

*   **Allow users to connect social logins to their accounts:** Enable this if you want existing users to link their UserSpice account.
*   **Prevent creating new users from social login:** Disable if you want auto-provisioning.
*   **Default group for new users from social login:** Assign users to a specific Nextcloud group.
*   **Show social login buttons on login page:** Ensure this is enabled.

**Testing:**

1.  Log out of Nextcloud.
2.  On the Nextcloud login page, you should see a "Login with UserSpice" (or similarly named) button.
3.  Click the button. You should be redirected to UserSpice.
4.  Log in with UserSpice credentials.
5.  Authorize Nextcloud if prompted.
6.  You should be redirected back to Nextcloud and logged in.
    *   If it's a new user and auto-provisioning is enabled, a Nextcloud account should be created.

**Troubleshooting:**

*   **Check Nextcloud Logs:** Administration settings > Logging.
*   **Check UserSpice OAuth Server Logs:** If available.
*   **Callback URL Mismatch:** This is the most common issue. Ensure the Redirect URI in UserSpice exactly matches what Nextcloud expects.
*   **Scope Issues:** Ensure the scopes requested grant access to the necessary user information fields.
*   **User Info Endpoint:** Verify that UserSpice's `/api.php` (or configured endpoint) returns the expected user data (especially the fields mapped in Nextcloud) when a valid access token is provided. You can test this with `curl` or Postman.
*   **HTTPS:** Both Nextcloud and UserSpice must use HTTPS.

**If Generic OAuth2 Fails (Need for a Custom Social Login Provider Class):**

If UserSpice's OAuth implementation or user info endpoint has peculiarities not handled by Nextcloud's generic OAuth2 client or the Social Login app's custom provider UI, a small PHP class might need to be developed for the Social Login app. This class would extend `OCA\SocialLogin\Provider\AbstractProvider` or a similar base and handle any specific transformations or API calls. This is beyond a simple configuration guide.

This guide focuses on configuration. Actual field names from UserSpice (`id`, `username`, `email`, `fname`, `lname`) should be verified against your UserSpice OAuth server's API response.
