Joomla UserSpice OAuth Authentication Plugin Notes
-------------------------------------------------

This directory (`userspiceoauth`) contains the files for a Joomla authentication plugin that allows users to log in using their UserSpice credentials via OAuth2.

**Plugin Files:**
- `userspiceoauth.xml`: The manifest file. Defines plugin metadata, parameters, and file structure.
- `userspiceoauth.php`: The main plugin logic, handling the OAuth flow and Joomla user authentication/creation.
- `language/en-GB/en-GB.plg_authentication_userspiceoauth.ini`: Language strings for runtime messages.
- `language/en-GB/en-GB.plg_authentication_userspiceoauth.sys.ini`: Language strings for plugin manager and configuration parameters.
- `index.html` files: Prevent directory listing.

**Installation:**

1.  **Package the Plugin:**
    *   Create a ZIP file containing all the files and folders within this `userspiceoauth` directory.
    *   The structure inside the ZIP file should be:
        ```
        userspiceoauth.xml
        userspiceoauth.php
        index.html
        language/
            en-GB/
                en-GB.plg_authentication_userspiceoauth.ini
                en-GB.plg_authentication_userspiceoauth.sys.ini
                index.html
            index.html
        ```
    *   Name the ZIP file something like `plg_authentication_userspiceoauth_v1.0.0.zip`.

2.  **Install in Joomla:**
    *   Log in to your Joomla Administrator backend.
    *   Navigate to "Extensions" > "Manage" > "Install".
    *   Under the "Upload Package File" tab, select the ZIP file you created and click "Upload & Install".

**Configuration:**

1.  **Enable the Plugin:**
    *   After installation, go to "Extensions" > "Plugins".
    *   Search for "Authentication - UserSpice OAuth".
    *   Enable the plugin by clicking the status icon (red X to green check).

2.  **Configure Settings:**
    *   Click on the plugin name ("Authentication - UserSpice OAuth") to edit its settings.
    *   You will need to configure the following:
        *   **UserSpice Server URL:** The full base URL of your UserSpice installation (e.g., `https://your-userspice-domain.com/usersc/`).
        *   **Client ID:** The Client ID for your OAuth client, obtained from the UserSpice OAuth Server plugin settings.
        *   **Client Secret:** The Client Secret for your OAuth client.
        *   **Authorization Endpoint Path:** Relative path to UserSpice auth endpoint (default: `plugins/oauth_server/auth.php`).
        *   **Token Endpoint Path:** Relative path to UserSpice token endpoint (default: `plugins/oauth_server/auth.php`).
        *   **User Info Endpoint Path:** Relative path to UserSpice API endpoint for user data (default: `plugins/oauth_server/api.php`).
        *   **Scope:** Space-separated scopes (e.g., `profile email`). `email` is crucial for linking accounts.
        *   **Auto-create Joomla User:** Enable if you want new Joomla users to be created automatically if they don't exist.
        *   **Default Joomla User Group:** The group assigned to newly created users.
        *   **Login Button Text (Informational):** Suggestion for button text.

3.  **Set Redirect URI in UserSpice:**
    *   In your UserSpice OAuth Server plugin configuration (for this client), you need to set the **Redirect URI**.
    *   The Redirect URI for this Joomla plugin will be your Joomla site's root `index.php`. For example:
        `https://your-joomla-site.com/index.php`
        Ensure this matches exactly what the plugin uses (which is `JURI::root() . 'index.php'`).

**Usage - Adding a Login Button/Link:**

This plugin **does not** automatically add a "Login with UserSpice" button to your Joomla login form. You need to do this manually. Here are a few ways:

1.  **Custom HTML Module:**
    *   Create a new Custom HTML module in Joomla ("Extensions" > "Modules" > "New" > "Custom").
    *   In the content, add a link or a button:
        `<a href="index.php?userspiceoauth=1" class="btn btn-primary">Login with UserSpice</a>`
        (You can use the text configured in the plugin settings if desired, e.g., "Login with UserSpice")
    *   Assign this module to the "login" position (or another suitable position) on the pages where you want the login option to appear (typically the login page).

2.  **Template Override:**
    *   Create a template override for the Joomla login component (`com_users` view `login`).
    *   In the override file (usually `components/com_users/views/login/tmpl/default_login.php` within your template's html directory), add the HTML for the button/link pointing to `index.php?userspiceoauth=1`.

3.  **Menu Item:**
    *   You could create a menu item of type "External URL" that points to `index.php?userspiceoauth=1` and label it "Login with UserSpice".

The key is that the link must point to a URL on your Joomla site that includes the query parameter `userspiceoauth=1`. This parameter triggers the plugin to start the OAuth flow.

**Important Notes:**
*   **HTTPS:** Both your Joomla site and UserSpice server should be running on HTTPS for security.
*   **UserSpice API:** The plugin assumes the UserSpice `/plugins/oauth_server/api.php` endpoint returns user data including at least `email` and `username`. Adjust `authenticateOrProvisionJoomlaUser` if your UserSpice API returns different fields.
*   **Error Logging:** The plugin logs errors to Joomla's logging system (e.g., `administrator/logs/everything.php` or as configured). Check these logs if you encounter issues.
*   **Session Management:** Ensure Joomla's session handling is working correctly. The `state` parameter relies on the session.
*   **Testing:** Test thoroughly, especially the user creation and login process for existing/new users.
